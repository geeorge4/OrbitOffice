# Orbit Office 1.1.2

Самостоятельный офисный редактор для Windows. Не является продуктом Microsoft.

Три отдельных окна для работы с текстом, таблицами и презентациями. У каждого редактора свой цвет, заголовок окна и черновик.

| Редактор | Назначение | Запуск |
| --- | --- | --- |
| Orbit Write | Документы | `Orbit Write.cmd` |
| Orbit Calc | Таблицы | `Orbit Calc.cmd` |
| Orbit Slides | Презентации | `Orbit Slides.cmd` |

Также можно запустить `Orbit Office.exe`. По умолчанию откроется Write. Кнопки редакторов в верхней панели открывают отдельные окна. Требуется Microsoft Edge WebView2 Runtime (обычно уже есть в Windows 10/11).

## Заставка и настройки

Пять летящих точек в стиле Office. По умолчанию заставка видна минимум **5 секунд**. Нажми **Настройки** в верхней панели, укажи длительность от 0 до 30 секунд и сохрани. Изменение применяется при следующем запуске любого редактора.

## Что работает

- Документы с оформлением текста, заголовками, списками, таблицами и картинками.
- Таблица на 100 строк и 26 столбцов. Ссылки на ячейки, арифметика, SUM, AVERAGE, MIN и MAX для диапазонов.
- Презентации с редактированием текста, выбором фона, добавлением, дублированием и удалением слайдов. Показ с клавиатурой.
- Автовосстановление трёх последних черновиков на этом компьютере.
- Сохранение проекта `.orbit`. Открытие DOCX, XLSX, PPTX, TXT. Экспорт DOCX, XLSX, PPTX.
- Ctrl+S, Ctrl+O. Печать документов через системный диалог.

## Ограничения первой версии

Формат `.orbit` сохраняет собственное оформление редактора. Импорт и экспорт Office переносят базовое содержимое: DOCX — текст абзацев, XLSX — значения и формулы первого листа, PPTX — текст слайдов. Сложное оформление, картинки в Office-файлах, диаграммы, макросы, комментарии и анимации PowerPoint не переносятся. Форматирование документа и встроенные картинки сохраняются в проекте `.orbit`, но не в DOCX. Формулы вне указанного набора могут экспортироваться в Excel, но не рассчитываются внутри приложения.

Исходные файлы не перезаписываются автоматически. Храни копию исходного Office-документа. Черновики находятся в `%LOCALAPPDATA%\OrbitOffice\recovery-write.json`, `recovery-sheet.json`, `recovery-slides.json`. Старый общий черновик читается для переноса без удаления. Настройки хранятся отдельно в `settings.json`. Несколько окон одного редактора используют общий черновик этого типа, поэтому сохраняй разные документы в отдельные проекты `.orbit`.

Интерфейс использует ленту и плавное появление страниц. Это первая версия, а не полная замена Microsoft Office.

## Запуск из исходников

Нужны Windows и Python 3.14.

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python app.py --kind write
.venv/Scripts/python app.py --kind sheet
.venv/Scripts/python app.py --kind slides
```

## Сборка

Активируй окружение и запусти `./build.ps1`. Сборка появится в `dist`. GitHub Actions собирает архив Windows вручную или при публикации тега версии. Сборка не запускает приложение и не выполняет тесты.
